设计说明

不是换一套皮肤，而是把「层级、节奏、状态」三件事重新排一遍。

01 / ONE ACCENT

一个强调色

珊瑚橙只出现在主操作、当前项和焦点上；其余交给中性色阶。语义色只负责成功 / 警告 / 错误，不参与装饰。

02 / THREE LEVELS

三档信息层级

14px 正文、11px 辅助、9.5px 元信息。消息类型靠结构与留白区分，而不是靠五种高饱和颜色。

03 / ONE COLUMN

一个阅读宽度

对话正文、工具卡、输入框统一 740px；行长控制在 50 个汉字左右，扫读成本和输入落点都更稳定。

现状里最值得改的

  • theme.css 里 60 多个色值散落各处，强调色与语义色混用，没有 token 层。
  • .root 固定 16px，输入 / 思考 / 工具 / 回复同一字号，类型只靠彩色标签。
  • 侧栏固定 25%，会话区 0.618 / 工作空间 0.382；只有一两个会话时出现大块空洞，新建按钮贯穿整栏。
  • 输入区 61.8% 宽居中，与 100% 宽的正文左边缘错位；聚焦边框与发送键同色，语义不清。
  • 标题栏「模型: xxx」只是一行文本；页签是第二层 chrome，活动页签像悬浮卡片，关闭键是灰圆点。
  • 工具调用、思考、统计行全是同一套彩色控制台行；运行指示器浮在左下角，靠 40px 底部内边距避让。

这版做了什么

  • 收成 5 个基础 token + 4 个语义色；珊瑚橙只做一件事：标记「当前」和「主要动作」。
  • 14px / 11px / 9.5px 三档；正文行高 1.7，辅助信息降到弱对比但不低于可读阈值。
  • 292px 固定侧栏：会话列表弹性，工作空间按内容收口，当前目录与版本常驻底部。
  • 740px 统一内容列；输入框与正文对齐，工具栏收进底部，发送键改为 32px 圆角主按钮。
  • 页签压到 28px；工作空间与模型变成可点 chip；窗口控制去掉常驻边框，只在 hover 时出现。
  • 用户气泡 / AI 头像 / 工具卡 / 思考卡 / 统计脚注五种稳定形态；运行态用页签绿点和行内呼吸点表达。
  • 运行状态从正文左下角浮层移到输入框上沿的状态行，页签与会话行只留呼吸点，不再为浮层预留 40px 底部内边距。

落地顺序

  1. 01Token 与外壳theme.css 色板、字号、圆角；标题栏、侧栏、页签、输入区的结构与间距。纯样式 + 局部布局，风险最低。
  2. 02消息流ChatView 按类型拆节点：用户气泡、AI 头像、工具卡、思考卡、统计行；保留现有事件流、折叠与流式合并逻辑。
  3. 03状态与细节空会话引导、运行态、确认卡片、滚动条与悬停反馈；补上「默认拒绝」的安全焦点。
  4. 04可选项会话搜索、按日期分组、工具耗时（需给事件加时间戳）。不影响主视觉，可后置。
