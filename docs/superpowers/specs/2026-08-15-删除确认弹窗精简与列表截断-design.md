# minion 删除确认弹窗精简与侧栏/页签截断 设计

日期：2026-08-15
状态：待确认

## 背景

GUI 验收清单中「需求 6」「需求 7」的遗留项：

- **需求 6**（部分完成）：确认退出弹窗已精简（fe8d670：去叹号图标/去 header 文字/正文居中/减一行），但用户明确要求「删除会话、删除工作空间的弹窗同样处理」——三处删除确认弹窗仍是默认样式（带叹号圆圈图标 + 左侧"确认"文字）。
- **需求 7**：侧栏会话列表标题/摘要已截断（57ee5c3），但**工作空间列表名称未截断**——长工作空间名把行撑出横向滚动条，悬停 ⚙（修改）/✕（删除）按钮被挤出可视区（"删除修改按钮不见"）；**顶部页签 Tab 标题也未截取**——长会话标题把页签撑宽，标题栏错乱。

## 需求 6 删除确认弹窗精简

现状三处删除确认（`Alert(CONFIRMATION)` + `Theme.style`）：

| 位置 | 消息 |
|------|------|
| [SessionListView.doDelete](src/main/java/com/minion/gui/sidebar/SessionListView.java) | 删除会话「…」？ |
| [MainWindow.addTab onCloseRequest](src/main/java/com/minion/gui/MainWindow.java) | 删除会话「…」？（页签 ✕ 关闭） |
| [WorkspaceListView.doDelete](src/main/java/com/minion/gui/sidebar/WorkspaceListView.java) | 删除工作空间「…」？… |

统一改为与退出确认弹窗相同处理（复用现有 `.dialog-exit` 样式类）：

```java
a.setHeaderText(null);                 // 去掉左边的"确认"文字（header 行移除 → 弹窗高度减一行）
a.getDialogPane().setGraphic(null);    // 去掉叹号圆圈图标
a.getDialogPane().getStyleClass().add("dialog-exit"); // 正文居中
```

`.dialog-exit .content { -fx-text-alignment: center; }` 已存在于 theme.css（fe8d670 添加），无需新增 CSS。

## 需求 7 列表/页签截断

### 7.1 工作空间列表名称截断（WsCell）

现状 [WorkspaceListView.WsCell](src/main/java/com/minion/gui/sidebar/WorkspaceListView.java)：`nameLabel` 无 `OverrunStyle.ELLIPSIS`、无 `minWidth(0)`，行 HBox 无宽度绑定——长名称时 ListView 出现横向滚动条，悬停 ⚙/✕ 按钮不可见。

改造（对齐 SessionCell 已验证的修法）：

```java
nameLabel.setTextOverrun(OverrunStyle.ELLIPSIS);
nameLabel.setMinWidth(0); // 允许收缩至省略号
// HBox row 宽度绑定 cell 宽（须依赖 insetsProperty 重算，同 SessionCell 的 CSS 异步坑）
row.maxWidthProperty().bind(Bindings.createDoubleBinding(
        () -> getWidth() - getInsets().getLeft() - getInsets().getRight() - 4,
        widthProperty(), insetsProperty()));
```

### 7.2 顶部页签标题截取（updateTab）

现状 [MainWindow.updateTab](src/main/java/com/minion/gui/MainWindow.java)：`t.setText(h.title)` 原文直设——JavaFX Tab 文本无省略机制，长标题把页签撑宽、标题栏错乱。

改造：标题超 16 字符截断加省略号，Tab 挂 Tooltip 显示完整标题（信息不丢失）：

```java
private static final int TAB_TITLE_MAX = 16;
String title = h.title;
if (title != null && title.length() > TAB_TITLE_MAX) title = title.substring(0, TAB_TITLE_MAX) + "…";
t.setText(title);
t.setTooltip(new Tooltip(h.title)); // 完整标题提示
```

（addTab 新建页签同样套用；`t.setText("(新会话)")` 的兜底逻辑不变。）
