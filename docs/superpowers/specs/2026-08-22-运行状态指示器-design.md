# 运行状态指示器（齿轮 + 动态文案）设计

日期：2026-08-22
状态：已确认

## 背景与动机

- 千问 3.6 等模型无思考过程、首次回复前耗时较长；工具调用耗时久时用户易误判「卡住了」。
- 需要运行时可见的「正在工作」反馈：正文区左下角转动的齿轮 + 动态文案。
- 上下文压缩期间需明确提示（压缩是同步阻塞调用，用户无法感知内部进展）。

## 需求

1. 正文区域（右侧消息区）左下角悬浮一个转动的齿轮（SVGPath，Timeline 旋转动画，2s/圈）。
2. 齿轮右侧文案：每 10 秒随机轮换 `正在加载中...` / `可随时补充信息...`（随机=可连续相同）。
3. 上下文压缩中固定显示 `上下文压缩中...`（不参与轮换），压缩结束恢复轮换。
4. 仅当前激活会话运行时显示；空闲/无活动会话隐藏（含停止全部动画，防泄漏）。

## 方案：独立组件 + 事件链路扩展

### 组件：gui/RunningIndicator.java（新建）

HBox（齿轮 + 文案 Label），状态驱动：

- `setRunning(boolean)`：false → 整体隐藏 + 停止齿轮旋转与文案轮换 Timeline（遵循 StatusDot 动画回收规约：动画引用节点，隐藏前必须 stop）；true → 显示 + 启动动画。
- `setCompressing(boolean)`：true → 文案固定为「上下文压缩中...」，暂停 10s 轮换；false → 恢复轮换（若仍在运行态）。
- 文案池：`正在加载中...` / `可随时补充信息...`；10 秒轮换用 Timeline（KeyFrame 10s + Random），全部 FX 线程，不引入线程调度。
- 文案池选择与状态优先级抽纯静态方法（可脱离 JavaFX 单测）。

### 挂载：MainWindow

- chatScroll 外包 `StackPane chatHost`（原 VBox right 中间位置由 chatHost 取代），指示器锚定 chatHost 左下角，悬浮于消息区之上，不占布局。
- 状态同步（当前激活会话 = `chatView != null ? chatView.handle() : null`）：
  - `onSessionActivated`：`indicator.setRunning(h.running)` + `setCompressing(false)`（切会话复位压缩态）
  - `clearChatPane`（删除会话/切工作空间）：`setRunning(false)` + `setCompressing(false)`
  - `onSessionRunningChanged(h, running)`：仅 `h == 当前激活会话` 时 `setRunning(running)`
  - `onCompressingChanged(h, compressing)`：仅 `h == 当前激活会话` 时 `setCompressing(compressing)`

### 压缩状态事件链路（新增）

1. `core/agent/AgentUi.java`：加 `default void onCompressingChanged(boolean compressing) {}`（default 空实现，SubAgentLoop 等现有实现零改动）。
2. `core/agent/AgentLoop.java`：两处压缩调用点包裹 try/finally：
   - 自动压缩（runUserTurn 循环内 shouldCompress 分支）
   - 手动 /compress（compactNow()）
   - `ui.onCompressingChanged(true)` → compress → `finally { ui.onCompressingChanged(false); }`（压缩同步阻塞，前后即「压缩中」窗口；异常也不残留状态）。
3. `gui/session/SessionController.java`：仿 askStateListener 加 `compressingStateListener`（`Consumer<Boolean>`），`onCompressingChanged` 转发。
4. `gui/session/SessionManager.java`：创建会话时注入 listener → `notifyCompressingChanged(h, compressing)`；`Listener` 接口加 `default void onCompressingChanged(SessionHandle h, boolean compressing) {}`（default 保护其他实现）。
5. `gui/MainWindow.java`：实现 `onCompressingChanged`，仅当前激活会话时转发给指示器。

## 样式

theme.css 新增指示器样式类：齿轮与文案浅色（灰），小字号，与主题协调。

## 测试

- RunningIndicator 纯逻辑静态方法单测：文案池随机选择、压缩态文案优先级、可见性状态机。
- AgentLoop 压缩前后回调顺序：压缩入口发 true、结束（含异常）必发 false（若现有测试基建可覆盖）。
- 回归：`JAVA_HOME="D:/javame/jdk1.8" mvn compile` + 相关测试通过。

## 不做（YAGNI）

- 不做多会话聚合状态（只反映当前激活会话）。
- 不做压缩进度百分比（压缩为一次性同步调用，无中间进度）。
- 不做齿轮大小/文案可配置。
