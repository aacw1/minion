# minion 自举控制台窗口隐藏 设计

日期：2026-08-16
状态：已确认（用户：默认隐藏 + 配置开关）

## 背景

jar 自举（2026-08-16 上线）在无控制台场景（双击 javaw / mintty 误判）用
`cmd /c start` + java.exe 开新控制台窗口。用户实测：GUI 启动时多出一个黑窗口，
希望默认隐藏，同时保留排障时恢复控制台的通道。

用户决策：**默认隐藏 + config.properties 开关 `boot.console`**（false=隐藏默认，
true=恢复现有控制台行为）。

## 方案

### 1. 配置项（规则 5：默认值文件同步）

`src/resource/config.properties` 新增：

```
# 自举控制台窗口：true=启动时开控制台窗口（排障看日志）；false=隐藏（默认，javaw 直启无窗口）
boot.console=false
```

Boot 在 Main 之前运行、不依赖 Config 类（零副作用：不生成外部文件），直接读
jar 同目录 `config.properties`，文件缺失/键缺失/非法值一律按默认隐藏处理。

### 2. 纯逻辑（JdkResolver 新增，可单测）

```java
/** javaw.exe 路径：java.exe 同目录推导（JDK 标准布局）；输入 null/非法返回 null */
public static String javawExe(String javaExe)

/** 控制台是否隐藏：读 boot.console 配置；缺文件/缺键/非法值 → true（默认隐藏） */
public static boolean consoleHidden(java.nio.file.Path configFile)
```

- `buildCommand` 签名与既有分支不变：隐藏模式复用 `newConsole=false` 形态
  （直接派生 `[exe, -jar, jarPath, --relaunched, args...]`），exe 换成 javaw.exe
- 开启模式（boot.console=true）：现有逻辑一字不改（java.exe + cmd start 开窗 /
  继承控制台）

### 3. Boot.relaunch 分派

```java
boolean hidden = JdkResolver.consoleHidden(Paths.get(jarDir, "config.properties"));
String exe = hidden ? JdkResolver.javawExe(d.javaExe) : d.javaExe;
boolean newConsole = hidden ? false : d.newConsole;
List<String> cmd = JdkResolver.buildCommand(exe, jarDir, jarPath, newConsole, args);
new ProcessBuilder(cmd).directory(new File(jarDir)).start();   // 既有 try/catch → errorExit 兜底
```

- javaw 直启无窗口：双击 javaw 自举、mintty 误判两条路径的额外窗口一并消失
- 子进程 stdout/stderr 随 javaw 丢弃（GUI 报错仍走既有 Swing 错误框 / 非模态 Alert）
- ERROR_NO_JVM / RUN_WITH_WARN 路径不受影响

### 4. 文档同步

- README 启动节：补 `boot.console` 开关说明；mintty 边界条目改写（默认隐藏后
  不再开窗，仅 boot.console=true 时保留原边界）
- CLAUDE.md：无需改（config.properties 三件套表在 README）

## 测试

`JdkResolverConsoleTest`（或并入既有 JdkResolverTest）：

1. `javawExe("C:\jdk\bin\java.exe")` → `"C:\jdk\bin\javaw.exe"`；null → null
2. `consoleHidden`：无配置文件 → true；`boot.console=false` → true；`boot.console=true` → false；
   键缺失 → true；非法值（如 `boot.console=yes`）→ true
3. buildCommand 既有测试不回归（签名未变）

验证：`mvn test` 全绿；冒烟——`java -jar`（无控制台场景）无新窗口、GUI 正常；
`boot.console=true` 时恢复开窗；双击 javaw 路径同样无窗口。
