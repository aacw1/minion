# 子代理消息配色对齐主代理 设计

日期：2026-09-18
状态：已实施（2026-09-18，全量测试通过 + 真机冒烟确认）
关联：本设计修改《2026-09-13-子代理报告落盘与压缩与消息标识-design》（其"独立配色"部分），
该设计的其余部分（【子代理N】标签、报告落盘、上下文压缩、不写历史）不变。

## 背景与问题

2026-09-13 设计为子代理事件统一挂独立配色（`log-subagent` #4dd0e1 / `log-body-subagent` #b3e5fc），
当初目的是"与主代理紫/蓝/灰区分"。实际使用中：子代理的思考、回复、工具调用与结果、错误、
警告、系统行，标签与正文**全部只有一种青色**，用户无法从颜色分辨子代理当前正在思考、回复
还是执行工具（"子代理正文颜色只有一个，不清晰"）。

主代理侧已有成熟的按类型配色体系（`.log-*` 标签色 + `.log-body-*` 正文色）：

| 消息类型 | 标签色 | 正文色 |
|---|---|---|
| 输入 | `log-input` #75aaff 蓝 | `log-body-input` #8cbcff 浅蓝 |
| 思考 | `log-think` #8c8c8c 灰 | `log-body-think` #9c9c9c 灰白 |
| 回复 | `log-reply` #bfbfbf 白 | `log-body-reply` #c9c9c9 白 |
| 工具 | `log-tool` #9C27B0 紫 | `log-body-tool` #ce93d8 浅紫 |
| 错误 | `log-error` #f85149 红 | 未定义 → 回退白 |
| 警告 | `log-warn` #e3b341 黄 | 未定义 → 回退白 |
| 系统/统计 | `log-sys` #16C60C 绿 | 未定义 → 回退白 |

## 需求（用户确认的决策）

- 子代理消息（**标签 + 正文**）按消息类型使用与主代理完全一致的颜色；主/子代理同色后，
  区分仅靠【子代理N】文字标签（用户确认接受）。
- 子代理「子任务开始/完成」边界行**保留青色** `log-subagent`，作为唯一子代理标识色，
  便于识别子代理块的范围（用户确认保留）。
- 主代理显示**完全不变**。

## 设计

### 1. 配色映射（改动后）

| 子代理事件 | 标签/正文样式类（与主代理同） | 效果 |
|---|---|---|
| 思考 THINKING | `log-think` / `log-body-think` | 灰标签 + 灰白正文 |
| 回复 CONTENT | `log-reply` / `log-body-reply` | 白标签 + 白正文 |
| 工具调用 TOOL_CALL | `log-tool` / `log-body-tool` | 紫标签 + 浅紫正文 |
| 工具成功 TOOL_RESULT(ok) | `log-tool` / `log-body-tool` | 同上 |
| 工具失败 TOOL_RESULT(err) | `log-error` / 回退白 | 红标签 |
| 错误 ERROR | `log-error` / 回退白 | 红标签 |
| 警告 WARNING | `log-warn` / 回退白 | 黄标签 |
| 统计 STATS / 系统 SYSTEM | `log-sys` / 回退白 | 绿标签 |
| 输入 USER_MESSAGE/SUPPLEMENT | `log-input` / `log-body-input` | 蓝标签 + 浅蓝正文 |
| 子任务开始/完成 SUB_AGENT_START/DONE | `log-subagent`（**不变**） | 青标签 + 浅青报告正文 |

### 2. 改动清单

1. **`gui/chat/ChatView.java`**
   - 删除 `colorOf(int, String)` 静态方法（已无逻辑职责：恒等映射）。
   - `onEventFx` 中 11 处调用点 `colorOf(id, "log-xxx")` 改为直接传 `"log-xxx"`：
     输入 ×2、思考、回复、工具 ×2、工具结果（ok ? tool : error）、错误、警告、统计、系统。
   - `SUB_AGENT_START` / `SUB_AGENT_DONE` 两处硬编码 `log-subagent` 保持不变。
   - `Seg` 构造器的 `log-body-*` 派生（`"log-body-" + tagColorClass.substring(4)`）不变，
     正文色自动跟随标签色类；`log-body-error/warn/sys` 无定义回退白与主代理一致。
   - 类头注释更新（去掉"子代理段带 log-subagent 配色"表述，改为配色与主代理同类型一致、
     青色仅边界行）。
2. **`resource/theme/theme.css`**
   - `.log-subagent` / `.log-body-subagent` 保留（仅开始/完成边界行使用），注释更新为
     "子代理开始/完成边界标识色"。
   - `log-*` / `log-body-*` 区块注释同步（说明子代理消息与主代理同色）。
3. **测试 `ChatViewStreamBufferTest.tag_subAgentVsMain`**
   - 删除两行 `colorOf` 断言（方法已删除），保留 `tagOf` 断言；注释更新。
4. **文档同步**
   - `docs/ARCHITECTURE.md`：ChatView 行"独立配色（`log-subagent`）"描述更新。
   - `README.md`：子代理章节"独立配色显示"描述更新。

### 3. 取舍说明

- **不做子代理专属色系**（如降饱和/降亮度变体）：用户明确"和主代理颜色一致"；可辨识性
  由【子代理N】标签与青色边界行承担。
- **不删 `.log-subagent`/`.log-body-subagent` CSS**：边界行仍在用。
- **不做渲染层测试**：配色属 JavaFX 渲染层（style class 断言需 FX 环境），本次以小改动 +
  手动冒烟验证；纯逻辑 `tagOf` 断言保留。
