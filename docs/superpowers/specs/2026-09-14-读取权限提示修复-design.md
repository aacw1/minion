# 读取文件权限提示修复：放行目录未创建与开关开启时的误报"越界拒绝"

日期：2026-09-14
状态：已实施（2026-09-14，全量测试通过 + 复现程序验证通过）

## 背景与问题

用户报：读取文件时，若路径属于「有权限」范围（会话临时目录、技能目录等），或已开启全局
读取开关（`paths.read.allowOutside`），文件不存在时应直接报「文件不存在」，不应附带
「路径在工作目录之外，访问将被拒绝」的越界提示。

## 复现（修复前实测，见下方证据）

| # | 场景 | 实际输出 |
|---|------|----------|
| A1 | 会话临时目录**尚未创建**，读其下不存在文件 | `文件不存在: ...（路径在工作目录之外，访问将被拒绝。当前工作目录: ...）` ❌ |
| C1 | 技能目录**尚不存在**时，读其下不存在文件 | 同上 ❌ |
| A2 | 会话临时目录**已存在**，读其下不存在文件 | `文件不存在: ...` ✅ |
| D | **开关开启**，读越界不存在文件 | `文件不存在: ...（路径在工作目录之外，访问将被拒绝。...）` ❌ |

（A2/B/C2 证明"目录存在"时行为正确；A1/C1/D 为误报。）

复现证据：临时程序直接调用 `ReadTool.execute`，输出如上表；相关代码
`src/main/java/com/minion/core/tools/ReadTool.java` 第 50-61 行「文件不存在」分支。

## 根因

两条独立根因：

1. **`PathsGuard.inside(dir, p)` 要求 dir 自身可 `toRealPath`**，dir 尚不存在时（会话临时目录
   为惰性创建——首次落盘才建目录；技能目录可能未安装/被删）直接返回 false → 放行目录下的
   路径被误判越界。`inside` 已处理「p 不存在」的半边（向上找最深已存在祖先），漏了
   「dir 不存在」的半边；`WriteTool.outsideGuard` 有 T8 约定自行绕过此坑，ReadTool 没有。
2. **ReadTool 的「文件不存在」分支完全没有感知读越界开关**：开关打开 = 全盘可读，
   但不存在路径仍给越界警告；分支内也没有任何 `ConfirmGate` 查询。

## 修复方案

1. **`PathsGuard.inside` 增加 dir 缺失兜底**：`dir.toRealPath()` 失败时退化为「规范化绝对路径
   前缀」词法比较（与 `WriteTool.insideLexical` 同口径）；dir 为 null/空仍返回 false。
   - 安全性：该兜底只可能作用于「dir 不存在 + p 不存在」的场景——p 存在时其祖先链必然存在，
     dir 为其祖先必已存在，不会进入兜底分支，真实路径校验（含 NOFOLLOW_LINKS 探活）不变。
   - 影响面已逐一核查：EditTool 先在存在性检查后才调用守卫（不受影响）；Write/Glob/Grep/
     BrowserScreenshot/Ssh 在 dir 不存在场景的行为变化方向一致（放行而非误拒），语义正确。
2. **`ConfirmGate` 新增 `readOutsideAllowed()`** = `config.readAllowOutside() || sessionBypass`
   （与 `checkReadOutside` 的放行口径完全一致，含用户已按 A/W 会话放行的情形）。
3. **ReadTool 不存在分支接入**：命中任一放行（workDir/额外放行目录/技能目录/会话临时目录/
   `readOutsideAllowed()`）→ 纯「文件不存在: p」；否则保留原越界提示（防模型编造路径的既有特性）。
4. **会话存储目录只读放行**（用户审查时确认新增）：`Workspace` 新增 `extraReadDirs`（只读放行
   目录列表，volatile 替换语义 + 热更新，与 `extraAllowedDirs` 同构）；`PathsGuard` 新增
   `insideReadExtra` / `errorIfOutsideRead`（读工具版本 = 读写放行 + 只读放行目录）；
   Read/Grep/Glob 改走 `errorIfOutsideRead`；`SessionManager.buildCtx` 与 `renameWorkspace`
   按 `<jarDir>/session/<空间名>` 设置/刷新。**写入不放行**：Write/Edit 仍走原守卫
   （覆写会话 JSON 仍被拒或需确认），只读语义不被写权限扩张。

覆盖的「有权限路径」清单：工作目录、额外放行目录（项目技能目录）、技能目录、会话临时目录
（`<jarDir>/.session/tmp/<sessionId>`，**即使目录尚未创建**）、会话存储目录
（`<jarDir>/session/<空间名>`，只读；**即使目录尚未创建**）、开关开启时的任意路径、
本会话已放行的越界读。

## 测试与验证

新增单测（先写失败用例再修）：

- `PathsGuardTest`：dir 不存在路径词的判定 2 例（在其下 true / 在其外 false）；只读放行目录
  （extraReadDirs）的放行 2 例（文件在其下放行、其外拒绝）；
- `FileToolsTest`：会话临时目录未创建时报纯「文件不存在」、技能目录未创建时同、开关开启时
  越界不存在文件报纯「文件不存在」、会话放行（APPROVE_SESSION）后同、开关关闭时仍保留
  越界提示（回归钉）；会话存储目录（只读放行）读取放行、其下不存在文件报纯「文件不存在」、
  Write 写入仍拒绝（只读语义钉）。

验证：`mvn test` 全量通过；临时复现程序重跑 A1/C1/D 场景确认输出为纯「文件不存在」。
