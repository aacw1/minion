# 正文滚轮加速设计

日期：2026-08-15
状态：已确认（用户审阅通过前为草案）

## 背景与问题

正文消息区（chatScroll，普通 `ScrollPane`，见 [MainWindow.java](../../../src/main/java/com/minion/gui/MainWindow.java) 建置处）走 JavaFX 8 `ScrollPaneSkin` 默认滚轮行为：按内容长度归一化的比例滚动，且对平滑滚轮的小数增量（每次事件 1~10px）处理粗糙、逐格跳。用户反馈：鼠标中键滚动太慢、不够丝滑，需要加速。

## 目标

- 滚轮加速：每格滚轮滚动**固定 100px**（约 6 行正文，浏览器同档），与内容长短无关，长短消息手感一致。
- 平滑滚轮连续跟手：增量按比例换算成像素，不跳格。
- 写死不配置：不进设置窗、不动 config.properties（用户 2026-08-15 确认）。
- 仅正文消息区，侧栏列表不动（用户 2026-08-15 确认）。

## 非目标

- 不做惯性甩动/缓动动画（用户确认选固定像素模型，排除「固定像素 + 惯性」）。
- 不改侧栏会话/工作空间列表的滚轮行为。
- 不做滚动速度设置项。
- 不改自动贴底策略（AutoScrollPolicy 零改动，靠现有 vvalue 监听联动）。

## 关键约束

- **JDK 8**，无新依赖。
- **零回归**：滚动条拖拽、键盘 PageUp/PageDown、Ctrl+滚轮（JavaFX 8 皮肤自带缩放）、Shift+滚轮均保持皮肤默认行为。
- 与自动贴底联动：手动滚离底部 → 自动跟随暂停；滚回底部 → 恢复（现有 vvalue 监听自动生效）。

## 实现设计（方案 A：事件过滤器 + 固定像素直改 vvalue）

### 行为定义

| 输入 | 行为 |
|------|------|
| 滚轮向下（deltaY < 0） | vvalue 增加：`newV = vvalue + pixels / scrollableHeight`，clamp ≤ 1.0 |
| 滚轮向上（deltaY > 0） | vvalue 减少：`newV = vvalue - pixels / scrollableHeight`，clamp ≥ 0 |
| 增量换算 | `pixels = deltaY × SCROLL_PIXELS_PER_NOTCH / 40.0`（Windows 每格 WHEEL_DELTA=40；平滑滚轮小数增量按比例连续换算） |
| 无滚动行程（scrollableHeight ≤ 0） | 不处理，放行给皮肤 |
| Ctrl / Shift 修饰 | 放行给皮肤（保留缩放等默认行为） |
| 水平增量 deltaX | 忽略（正文 fitToWidth，无水平滚动） |

- `scrollableHeight = 内容高 − 视口高`，每次事件实时读取（会话切换换 content 后自动正确）。
- 换算公式以 `newVvalue(vvalue, deltaY, scrollableHeight)` 纯函数呈现，供单测。

### 结构

新建 `src/main/java/com/minion/gui/WheelScrollAccelerator.java`：

```java
/** 正文消息区滚轮加速：每格固定像素滚动（替换 JavaFX 8 皮肤默认比例滚动），
 *  平滑滚轮增量连续换算不跳格。静态挂接，随 ScrollPane 生命周期共存。 */
public class WheelScrollAccelerator {

    /** 每格滚轮滚动像素（Windows 一格 = 40，平滑滚轮按比例换算） */
    static final double SCROLL_PIXELS_PER_NOTCH = 100.0;
    /** Windows 一格滚轮的 deltaY 基准值（WHEEL_DELTA） */
    private static final double DELTA_PER_NOTCH = 40.0;

    /** 挂接滚轮加速到 ScrollPane（正文消息区构造后调用一次；换 content 无需重挂） */
    public static void attach(ScrollPane pane) {
        pane.addEventFilter(ScrollEvent.SCROLL, e -> {
            if (e.isControlDown() || e.isShiftDown()) return; // 放行皮肤默认（缩放等）
            double scrollable = scrollableHeight(pane);
            if (scrollable <= 0) return;
            double v = newVvalue(pane.getVvalue(), e.getDeltaY(), scrollable);
            pane.setVvalue(clamp(v)); // setVvalue 越界值 JavaFX 自动钳制，此处显式 clamp 保证语义清晰
            e.consume(); // 阻止皮肤二次滚动
        });
    }

    /** 纯函数：滚轮增量 → 新 vvalue（[0,1] 外值由调用方 clamp） */
    static double newVvalue(double vvalue, double deltaY, double scrollableHeight) {
        return vvalue - deltaY * SCROLL_PIXELS_PER_NOTCH / DELTA_PER_NOTCH / scrollableHeight;
    }

    /** 实时可滚动行程：内容高 − 视口高（未布局完成时为 0 → 不处理） */
    private static double scrollableHeight(ScrollPane pane) {
        Node content = pane.getContent();
        if (content == null) return 0;
        return content.getLayoutBounds().getHeight() - pane.getViewportBounds().getHeight();
    }

    private static double clamp(double v) { return v < 0 ? 0 : (v > 1 ? 1 : v); }
}
```

- 挂接点：MainWindow 建好 chatScroll 后 `WheelScrollAccelerator.attach(chatScroll)`（与 `setupAutoScroll()` 并列调用一次）；会话切换 `setContent` 换 ChatView 无需重挂——每次事件实时读高度。
- 放行分支（Ctrl/Shift/无行程）不 `consume()`，皮肤继续默认处理，行为与现状一致。

### 与自动贴底联动

无需改 AutoScrollPolicy：本加速器写 vvalue 走现有 `vvalueProperty` 监听 → `policy.sync` 重算贴底。滚离底部贴底暂停、滚回底部恢复，与拖拽滚动条完全同路径。

## 测试

新增 `WheelScrollAcceleratorTest`（JUnit4，纯函数矩阵）：

| 用例 | 输入 | 期望 |
|------|------|------|
| 向下滚一格 | vvalue=0.5, deltaY=-40, scrollable=1000 | 0.5 + 100/1000 = 0.6 |
| 向上滚一格 | vvalue=0.5, deltaY=40, scrollable=1000 | 0.5 − 0.1 = 0.4 |
| 平滑滚轮小数增量 | deltaY=-4（格值 1/10） | 0.5 + 0.01 = 0.51 |
| 无行程不除零 | scrollable=0 / 负数 | 纯函数不抛异常（double 除零得 ±Infinity；拦截在 attach 放行分支，测试只断言公式无异常） |
| 零增量 | deltaY=0 | vvalue 不变 |
