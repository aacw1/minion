# 压缩中防重复点击 设计文档

日期：2026-08-28
状态：已批准（brainstorming 会话确认：只改 UI 层，不加核心层 compactNow 重入保护）

## 背景

环形进度圈（ContextRing）点击压缩存在防重漏洞：点击判定只看 `running` 与占比（>30%），
不区分"会话运行中"与"压缩进行中"两种状态，导致：

- **手动压缩时**（`compactNow`，此时 `running=false`）旋转动画期间仍可重复点击，
  向单线程池排队提交多个压缩任务，依次执行产生冗余 LLM 调用；
- **自动压缩时**（runUserTurn 内 `shouldCompress → compress`）虽因 `running=true` 不可点击，
  但 Tooltip 文案显示的是"运行中不可压缩"，与用户期望的"正在压缩中"不符。

自动/手动两条压缩路径都会推送 `ui.onCompressingChanged(true/false)` →
`InputView.setCompressing` → `contextRing.setCompressing`，GUI 侧 `compressing` 状态
对两条路径均完整覆盖，因此只需在 UI 层利用该状态补防重与文案。

## 目标 / 非目标

目标：
- 自动压缩时不可点击，Tooltip 第二行文案"正在压缩中"
- 手动压缩时不可点击，Tooltip 第二行文案"正在压缩中"
- 消除"点击提交 → 状态推送"之间的毫秒级窗口期二次点击

非目标：
- 不修改 core 层 compactNow（不加重入标志；/compact 命令连发、已排队任务仍可能
  重复执行压缩——已确认不在本次范围）
- 不改变压缩逻辑、阈值、动画本身

## 改动点（全部在 UI 层）

### 1. 可点击判定纳入压缩态（ContextRing.java）

静态纯函数扩展参数（保持可单测）：

```java
static boolean compressable(boolean compressing, boolean running, double pct) {
    return !compressing && !running && pct > COMPRESS_HINT_PCT;
}
```

点击回调同步更新：

```java
setOnMouseClicked(e -> {
    if (compressable(compressing, running, pct()) && onCompress != null) onCompress.run();
});
```

### 2. Tooltip 文案优先级（ContextRing.refreshTooltip）

第二行文案优先级：`compressing`（"正在压缩中"）> `running`（"运行中不可压缩"）>
超 30%（"点击立即压缩"）> 空。

```java
boolean over = pct() > COMPRESS_HINT_PCT;
if (compressing) {
    hintLine.setText("正在压缩中");
} else {
    hintLine.setText(over ? (running ? "运行中不可压缩" : "点击立即压缩") : "");
}
hintLine.setVisible(over || compressing);
hintLine.setManaged(over || compressing);
```

注意：可见性用 `over || compressing`——手动 `/compact` 可能在占比 ≤30% 时触发，
压缩中必须显示"正在压缩中"。

### 3. 消除点击到状态推送的窗口期（InputView.onCompress）

点击提交压缩任务后（FX 线程内）立即置压缩态，堵住"提交 → 工作线程
onCompressingChanged(true) → Platform.runLater 回投"之间的二次点击窗口：

```java
contextRing.setCompressing(true); // 提交后立即防重；onCompressingChanged(false) 自然恢复
h.pool.execute(...compactNow...);
```

## 覆盖情况核对

| 场景 | compressing | running | 可点击 | Tooltip 第二行 |
|------|-------------|---------|--------|----------------|
| 自动压缩中 | true | true | 否 | 正在压缩中 |
| 手动压缩中 | true | false | 否 | 正在压缩中 |
| 运行中（未压缩） | false | true | 否 | 运行中不可压缩 |
| 空闲且 >30% | false | false | 是 | 点击立即压缩 |
| 空闲且 ≤30% | false | false | 否 | （空） |
