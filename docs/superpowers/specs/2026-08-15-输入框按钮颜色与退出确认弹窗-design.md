# minion 输入框按钮颜色与退出确认弹窗改造 设计

日期：2026-08-15
状态：待确认

## 背景

GUI 验收提出两项 UI 改造：

1. **需求 4**：输入框聚焦时边框颜色改为 `#f48771`，不聚焦时颜色不变；确认（发送）按钮颜色随状态变化：内容空时 `#f48771`，有内容时 `#ff947c`，运行中 `#f48771`。
2. **需求 6**：确认退出弹窗去掉叹号圆圈图标、去掉左边的"确认"文字，剩余文字居中显示，弹窗高度减一行。

## 需求 4.1 输入框聚焦边框色

现状：输入区大框 `.input-frame` 边框 `#232733`（theme.css 第 70 行），聚焦/失焦无差异。

JavaFX 8 无 `:focus-within` 伪类，且边框挂在大框（frame）上而非 TextArea 自身（TextArea 背景透明），无法用纯 CSS 伪类表达，须代码切换样式类：

- [InputView](src/main/java/com/minion/gui/input/InputView.java) 现有 `input.focusedProperty()` 监听器（第 78 行）中追加：
  - 聚焦：`frame.getStyleClass().add("input-frame-focused")`
  - 失焦：`frame.getStyleClass().remove("input-frame-focused")`
- 注意：`frame` 字段初始化（构造器中部）晚于该监听器注册（构造器前部），监听器内须判空；后续每次聚焦/失焦时 frame 已非空，判空无副作用。
- theme.css 新增：

```css
.input-frame-focused { -fx-border-color: #f48771; }
```

- 边框宽度/圆角不变，仅换色；失焦即还原 `#232733`（原值不变）。

## 需求 4.2 确认按钮三态颜色

现状：发送按钮（上箭头/终止方块）六种模式（`BtnMode`）统一 `btn-danger`（红渐变），空输入/提问挂起空时叠加 opacity 0.35 变淡。

目标映射（`buttonStyleClass` 按模式返回样式类）：

| BtnMode | 语义 | 背景色 | 样式类 |
|---------|------|--------|--------|
| SEND | 有内容可发送 | `#ff947c` | btn-send-full |
| SEND_DIM | 内容空（变淡） | `#f48771` | btn-send-empty |
| SUPPLEMENT | 运行中+有内容 | `#f48771` | btn-send-empty |
| ANSWER | 提问挂起+有内容 | `#ff947c` | btn-send-full |
| ANSWER_DIM | 提问挂起+空（变淡） | `#f48771` | btn-send-empty |
| STOP | 运行中+空（终止方块） | `#f48771` | btn-send-empty |

判定：运行中（SUPPLEMENT/STOP）与内容空（SEND_DIM/ANSWER_DIM）→ `#f48771`；有内容且非运行（SEND/ANSWER）→ `#ff947c`。

- [InputView.java](src/main/java/com/minion/gui/input/InputView.java) `buttonStyleClass`（第 390 行）改为 switch 返回新类；`applyStyle`（第 421 行）的 `removeAll` 需同时移除新旧两类名，避免模式切换时旧类残留冲突。
- SEND_DIM/ANSWER_DIM 的 opacity 0.35 变淡逻辑保持不变（仅颜色改造）。
- theme.css 将 `.btn-danger`（仅 InputView 使用，grep 实证无其他引用）替换为两个新类，保留 hover：

```css
.btn-send-empty { -fx-background-color: #f48771; -fx-text-fill: white; -fx-font-weight: bold; -fx-background-radius: 8; }
.btn-send-empty:hover { -fx-background-color: #f69b85; }
.btn-send-full { -fx-background-color: #ff947c; -fx-text-fill: white; -fx-font-weight: bold; -fx-background-radius: 8; }
.btn-send-full:hover { -fx-background-color: #ffa894; }
```

（hover 取原色向浅方向微调，保持渐变观感替代。）

## 需求 6 确认退出弹窗

现状：[MainWindow.confirmClose](src/main/java/com/minion/gui/MainWindow.java)（第 263 行）用 `Alert(CONFIRMATION, ...)`：

- 中文 locale 下 JavaFX 8 AlertType.CONFIRMATION 默认 headerText 为"确认"（显示在弹窗左上方），graphic 为叹号圆圈图标——即用户所述"叹号圆圈图标 + 左边的确认文字"。

改造：

```java
Alert a = new Alert(Alert.AlertType.CONFIRMATION,
        "仍有会话正在运行，确认退出？", ButtonType.OK, ButtonType.CANCEL);
a.setHeaderText(null);                 // 去掉左边的"确认"文字（header 行整体移除 → 高度减一行）
a.getDialogPane().setGraphic(null);    // 去掉叹号圆圈图标
a.getDialogPane().getStyleClass().add("dialog-exit");
Theme.style(a);
a.setTitle("退出确认");
```

- header 行移除后弹窗自然少一行；graphic 移除后 content 文字左对齐，配合样式类居中：

```css
.dialog-exit .content { -fx-text-alignment: center; }
```

- 样式类限定 `.dialog-exit`，不影响 SettingsDialog 中其他 Alert（删除模型确认/错误提示）的默认布局。
- 按钮行（确定/取消）不动。
