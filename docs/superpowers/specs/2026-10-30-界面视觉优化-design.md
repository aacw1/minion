# 界面视觉优化（深色工作台 v1）设计

日期：2026-10-30
状态：已实施（2026-10-30，编译 + 全量测试通过；真实 GUI 冒烟）
关联效果页：`docs/ui-redesign/minion-ui-preview.html`（实施前的视觉方向稿；搜索/空态/日期分组等已按确认范围移除）
关联实现截图：未提交（截图含本地会话内容，以实际运行界面为准；方向稿截图见 `docs/ui-redesign/preview.png`）

## 一、背景

当前主界面是深色控制台风格：`theme.css` 中 60 余个散落色值、根字号 16px、
正文与输入框宽度不一致、侧栏固定 25% + 0.618 分区、消息类型靠五种高饱和颜色标签区分。
用户已确认按效果页做一版视觉优化。

## 二、用户确认的边界

- **整版落地**：外壳（标题栏 / 侧栏 / 页签 / 输入区）+ 消息流一起改。
- **只改效果，不加功能**：
  - 不加会话搜索；不加"今天/昨天"日期分组；不加工作空间路径/版本/会话计数；
  - 不加新的按钮入口（模型/工作空间标签保持静态展示）；
  - 新会话正文区域**留空**，不显示空状态引导或占位提示；
  - 确认卡片只改样式，**保留现有按钮顺序与默认「同意」**（不改键盘行为）。
- 保留现有全部交互与数据行为：会话/工作空间 CRUD、页签、流式、折叠、选择复制、
  截断保活、自动滚动、输入模式、@/ 补全、图片上传、上下文环、确认/白名单。

## 四、改动清单

### 1. `gui/icon/IconFactory.java`

新增 `spark`（品牌/助手头像/思考）、`plus`（新建会话/工作空间）、`alert`（确认卡片）三个 Material 路径。

### 2. `gui/TitleBar.java`

- 左侧：珊瑚色圆角品牌标 + `minion` 字标；模型标签移到右侧，改为静态 pill（绿点 + 模型名），
  不加下拉/点击行为；窗口按钮改为图标按钮，关闭按钮 hover 红。
- 保留拖动、双击最大化、最小化/最大化/还原、设置入口；`modelLabel()` 访问器保留。

### 3. `gui/MainWindow.java`

- 中部 GridPane 左列改为固定 292px，右列 `HGrow`；去掉 25%/75%。
- 侧栏：新增「会话」标题行（标题 + 新建按钮），删除贯穿整栏的「＋ 新建会话」；
  工作空间同样改为标题行 + `+` 图标，删除贯穿整栏按钮；删除 0.618/0.382 高度监听，
  工作空间按内容高度收口，会话列表占满剩余高度。
- 右侧 VBox 间距 0；页签栏、消息区、输入区连续；页签为空时整行隐藏的行为不变。
- 顶部模型标签文本改为纯模型名（不带「模型:」前缀）。
- 运行指示器保留原有左下角悬浮位置与全部状态逻辑，仅改样式（不改可见性口径）。

### 4. `gui/sidebar/SessionListView.java` / `WorkspaceListView.java`

- 会话行：标题 12.5px、摘要 10.5px（新 `.cell-summary`，不再复用 `.section-title`）、
  时间 10.5px；保留运行状态点、悬停重命名/删除、摘要截断与 60s 时间刷新。
- 工作空间行：保留单击切换、悬停修改/删除、拖拽排序、当前项圆点；
  列表按内容高度设置 `prefHeight`（最多 4 行，超出滚动），不改变数据操作。

### 5. `gui/input/InputView.java`

- 输入框由 19.1/61.8/19.1 百分比列改为 740px 上限居中，输入区与正文同宽。
- 底部操作行仍为上传 / 上下文环 / 发送；不加 `@`、`/` 等新按钮。
- 输入框下方新增一行纯文本快捷键提示（Enter/Ctrl+Enter 依配置），占位文案缩短。
- 不改变发送/终止/补充/回答模式、STOP 防抖、图片、粘贴块、补全弹层。

### 6. `gui/chat/ChatView.java` / `CollapsibleText.java`

- `ChatView` 顶部对齐居中，每行最大宽度 740；正文区左右不再铺满。
- 消息分型（全部保留原事件流与流式引用）：
  - 用户消息：右对齐气泡（只读 TextArea，保持选择复制）；
  - 回复：24px 头像 + 名称 + 正文；
  - 思考/工具/子任务：紧凑卡片，复用现有 `CollapsibleText` 折叠/懒挂载；
  - 错误/警告：带图标的横幅；
  - 系统/统计：弱化脚注行；
  - 用户消息无时间戳（EventList 不携带时间，不伪造）。
- **删除空会话占位提示**：`EMPTY_HINT` / `hint()` 删除，`clear()` 后正文为空白。
- 保留：流式合并（80ms）、思考定稿、子代理隔离、活动流引用、焦点治理、MAX_SEGS 截断、
  `minHeight=prefHeight`、TextArea 高度自适应、选择复制、折叠懒挂载。
- `CollapsibleText` 的 toggle 增加 `collapse-header` 类，便于卡片头部样式；
  折叠态不挂载内容体、折叠态文本为空等约定不变。

### 7. `gui/dialog/ConfirmSheet.java`

- 加标题、风险 pill、底部 Esc/Enter 提示；消息区与按钮区卡片化。
- 按钮顺序、默认「同意」、Esc/Enter、白名单/本会话语义均不变。

### 8. `resource/theme/theme.css`

- 全量替换色板与字号；新增品牌标、模型 pill、会话/工作空间标题行、消息气泡/头像/卡片/
  横幅/脚注、输入提示等样式；更新弹窗/下拉/滚动条/页签/按钮的深色样式。
- **LCD 关键约束**：`MessageTextArea .content` 必须是不透明背景且与所在表面一致
  （聊天 `#0B0F15`、用户气泡 `#1A2431`、工具卡 `#0E151D`、思考卡 `#0D131A`、
  横幅 `#211416`/`#201B10`），否则 JavaFX 8 回退灰阶 AA，正文发虚。

## 五、明确不做

- 会话搜索、日期分组、工作空间路径/版本/计数、空状态引导卡；
- 模型/工作空间标签点击入口、页签 `+` 新建入口、输入区 `@`/`/` 快捷按钮；
- 确认卡片默认拒绝（行为变更）；
- 设置窗结构重做（仅继承新色板与字号）；
- 任何非视觉的 Agent/LLM/工具行为改动。

## 六、风险与验证

- **ChatView 重构**是主要风险：必须回归流式、并发子代理、思考折叠、工具卡展开、
  长会话截断、选择复制、切会话/重放。
- **TextArea 背景**：逐表面核对 `.content` 背景，避免正文发虚。
- **性能**：不增加每段 TextArea 数量；卡片只增加轻量容器；保留折叠懒挂载。
- **JavaFX 8 限制**：无 CSS 变量/网格/过渡；用 VBox/HBox + padding 与硬编码色值。
- 验证：`mvn compile` + `mvn test`；启动真实 GUI 冒烟（新建会话空白、发消息、工具卡、
  折叠、切会话、确认卡片、设置窗）。
