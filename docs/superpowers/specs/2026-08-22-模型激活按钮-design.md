# 模型激活按钮 设计文档

日期：2026-08-22
分支：feat/model-activate-button
状态：已确认，待实施

## 背景与需求

设置窗模型页当前为"单击模型行即激活"（`SettingsDialog.modelPane` 的单击监听直接
`models.setCurrent + manager.applyModelChanged`）。用户有时只想查看模型配置，误点后
模型被切换，影响当前会话（需求 13 下切换是全量生效）。

需求（用户已确认）：

1. 点击模型行不再直接激活，只选中该行；查看配置沿用"修改"按钮
2. 在底部按钮行增加"激活"按钮（方案 B）
3. 选中的模型已是当前模型时，"激活"按钮置灰；点击激活后按钮重新置灰

## 方案选择

| 方案 | 内容 | 结论 |
|------|------|------|
| A 行内激活按钮 | 定制 cellFactory，选中行右侧显示激活按钮 | 未采纳（改动较大，用户选 B） |
| **B 底部按钮栏加"激活"** | 在 新建/修改/删除 旁加激活按钮，按选中项启用/置灰 | **采纳** |
| C 右侧详情面板 | 选中后展示只读详情 + 激活 | 未采纳（超出范围） |

## 交互设计

- 模型列表单击：仅选中行，不再触发任何激活动作；键盘上下键导航同样只改选中
- 底部按钮行顺序：`激活 | 新建 | 修改 | 删除`（激活放最前，语义首要）
- 激活按钮状态：
  - 选中模型 ≠ 当前模型 → 可点击
  - 选中模型 = 当前模型 或 无选中 → 置灰（`setDisable(true)`）
- 点击"激活"：`models.setCurrent(name)` + `manager.applyModelChanged()`（沿用需求 13
  全量生效）+ `refresh(list, models)`；● 移到新当前行，按钮因选中项变为当前模型而置灰
- ● 标记逻辑不变；新建/修改/删除及其 `applyModelChanged` 调用不变

## 实现要点

改动集中在 `src/main/java/com/minion/gui/dialog/SettingsDialog.java` 的 `modelPane`：

1. 删除 `list.setOnMouseClicked` 中的激活分支（整个监听可移除，单击选中为 ListView 默认行为）
2. 新增包可见静态判定方法：
   ```java
   /** 选中项可激活：非空且不同于当前模型 */
   static boolean canActivate(String selectedName, String currentName) {
       return selectedName != null && !selectedName.equals(currentName);
   }
   ```
3. 新增"激活"按钮（沿用 `btn-ghost` 样式），动作：
   ```java
   int idx = list.getSelectionModel().getSelectedIndex();
   if (idx < 0) return;
   String name = list.getItems().get(idx);
   if (name.equals(models.currentName())) return; // 双保险
   models.setCurrent(name);
   manager.applyModelChanged();
   refresh(list, models);
   ```
4. 监听选中变化同步按钮状态（覆盖鼠标点击、键盘导航、refresh 重选）：
   ```java
   list.getSelectionModel().selectedItemProperty().addListener(
       (obs, o, n) -> activate.setDisable(!canActivate(n, models.currentName())));
   ```
   注意监听器在首次 `refresh` 之后注册，首次选中不会触发回调，
   因此创建按钮时显式初始化：`activate.setDisable(true)`
   （首次 refresh 必选中当前模型，初始恒为置灰）；此后由监听器接管。

## 边界情况

- 无选中（理论上 refresh 总会选中一项，但删除/异常路径可能出现）→ 置灰
- 选中当前模型 → 置灰；激活动作内再做 equals 判断作双保险
- 删除当前模型后 current 回落 → `refresh` 选中回落项 → 按钮置灰，行为一致
- 新建模型后 `refresh` 选中 current → 按钮置灰
