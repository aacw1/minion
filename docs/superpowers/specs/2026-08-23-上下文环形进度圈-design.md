# 上下文环形进度圈 设计文档

日期：2026-08-23
状态：已批准（brainstorming 会话确认三项决策：点击环形圈本体压缩、关键节点刷新、压缩不确认）

## 背景

当前上下文占用仅在每轮结束时以统计行文字形式出现（`StatsLine`），用户无法实时感知上下文水位，
也没有主动压缩入口。参考 Claude VSCode 的 context 指示器，在输入框上传图标右侧新增环形进度圈：
实时按百分比显示进度，悬停查看详情，超过 30% 点击环形圈本体立即压缩。

## 目标 / 非目标

目标：
- 上传图标右侧环形进度圈，实时（关键节点粒度）反映当前会话上下文占比
- 悬停显示：上下文大小（k 单位）、占比百分比、剩余 x% 自动压缩
- 超过 30% 时悬停第二行显示浅色"点击立即压缩"提示文字；点击环形圈本体直接压缩
- 压缩过程中环形旋转动画

非目标：
- 不做悬停卡片内可点击链接（已确认点击动作在环形圈本体）
- 不加 30% 配置项（代码常量，YAGNI）
- 不改造自动压缩逻辑本身

## 交互决策（brainstorming 已确认）

1. **点击形式**：超过 30% 时点击环形圈本体触发压缩（Claude VSCode 风格）；悬停只展示信息，
   第二行"点击立即压缩"为纯提示文字（浅色、不可点击）
2. **刷新粒度**：关键节点推送——用户消息入历史后、模型回复完成、工具结果入历史后、
   压缩完成、每轮结束（不做流式逐字刷新）
3. **确认**：点击直接压缩，无二次确认（压缩保留最近 keepRecent 条原文，失败自动降级）

## 组件设计

### ContextRing（新类，`com.minion.gui.input`）

- JavaFX `Canvas` 自绘：背景圆环（底色）+ 进度弧（百分比对应角度，圆角线帽），尺寸约 20×20
- 颜色：
  - ≤30%：中性灰蓝 `#3a4150`
  - >30%：主题橙 `#f48771`（与发送按钮同系，可压缩提示色）
  - hover 微亮
- 状态：
  - 无会话 / 上下文不可用（used≤0 或 max≤0）：`visible=false, managed=false` 不占位
  - 压缩中（`onCompressingChanged(true)`）：旋转动画（Canvas 重绘旋转角）
- 纯静态方法 `arcAngle(double pct)` 计算进度弧角度，可脱离 JavaFX 单测

### 布局

`InputView` 底部操作行改为：`[uploadButton, contextRing, spacer, sendButton]`
（上传按钮右侧，HBox spacing 8 内）。

### 悬停信息（Tooltip）

- JavaFX `Tooltip`，延迟调小（如 300ms）
- 第一行：`上下文大小 98k，占比 70%，剩余 10% 自动压缩`
  - 大小复用 `StatsLine.formatTokens`（k 格式）
  - 剩余 = `threshold*100 − 当前占比`（threshold 从 ContextManager 实时读取；负数显示 0）
  - 无会话时显示 `上下文大小 0，占比 0%，剩余 x% 自动压缩`（或隐藏 Tooltip）
- 第二行（仅 >30%）：`点击立即压缩`，浅色（`-fx-text-fill` 淡化），纯提示
- 运行中悬停：第二行（>30% 时）显示 `运行中不可压缩`，点击无效
- 文案格式化 `formatTooltip(int used, int max, double threshold, boolean over30, boolean running)`
  为纯静态方法，可单测

## 数据流

### AgentUi 扩展

`AgentUi` 新增默认方法（不破坏现有实现类）：

```java
default void onContextStats(int used, int max) { }
```

### AgentLoop 推送

抽私有方法 `pushContextStats()`（内部 `contextManager.estimate(session.messages)` + `maxTokens()` + `ui.onContextStats`），
在以下关键节点调用：
- `runUserTurn` 用户消息入历史后
- 模型流式回复完成（`streamChat` onFinish 后）
- 工具结果入历史后
- 压缩完成后（含自动压缩）
- 每轮结束（与现有 `onStatsLine` 同一位置，可合并计算避免重复 estimate）

`contextManager == null` 时不推送（不启用压缩的场景）。

### GUI 转发

- `MainWindow` 监听 `SessionManager.Listener` 的上下文统计转发（在 `SessionManager` 的
  `AgentUi` 桥接中调用 `onContextStats` 后由 MainWindow 转发到 `inputView.onContextStats(h, used, max)`）
- 现有 `SessionManager.Listener` 模式扩展：新增 `onContextStatsChanged(SessionHandle h, int used, int max)`
  （default 空实现）
- `InputView.onContextStats(SessionHandle h, int used, int max)`：仅当 `h == current` 时更新并重绘

### 手动压缩

`AgentLoop` 新增：

```java
public void forceCompress() { ... }
```

- 提交到会话工作线程（`SessionHandle.pool.execute`），不阻塞 FX 线程
- 执行序列：`ui.onCompressingChanged(true)` → `contextManager.compress` → `ui.onCompressingChanged(false)`
  → `pushContextStats()`；压缩有缩减时发 `onWarning`（复用现有自动压缩提示文案）
- 运行中（`running`）调用无效：静默忽略（Tooltip 已提示"运行中不可压缩"）
- `contextManager == null` 时忽略
- 压缩失败：走现有 `compress()` 失败降级路径，返回原列表，不报错

### 阈值常量

`ContextRing`（或 InputView）内 `static final double COMPRESS_HINT_PCT = 0.3;` 代码常量。

## 样式 / 主题

- `theme.css` 无新增必需类（Canvas 颜色代码内联）；Tooltip 第二行浅色用代码内联 `-fx-text-fill`
  （Tooltip 深色主题由现有主题覆盖，两行文本在深底上）
