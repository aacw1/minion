# 消息区截断保活 200 段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ChatView 显示层按消息段条数截断（上限 200 段），长会话滚动不再卡顿，且截断时历史区视口不跳动。

**Architecture:** ChatView 在 `append()` 尾部检查段数，超 200 时同步删除头部多余段（`segs` 与 `getChildren()` 对齐删）；删除后通过注入的监听回调被删高度，MainWindow 在布局完成后按"视口顶部绝对位置守恒"公式补偿 vvalue。EventList 保持全量（纯内存缓冲，重放时截断同样生效）。

**Tech Stack:** Java 8 / JavaFX 8 / Maven。构建命令：`JAVA_HOME="E:/javame/jdk8" mvn clean package`；测试：`JAVA_HOME="E:/javame/jdk8" mvn test`。

## Global Constraints

- JDK 8 兼容，不使用 Java 9+ API（如 `List.of`）。
- 截断只发生在 `append()`（新段产生路径）；流式就地更新（THINK/REPLY 末段 `setText`）不触发截断。
- 截断只动头部段（`segs` 头部），永不触碰尾部正在流的段。
- `segs` 与 `getChildren()` 顺序一一对应（每段一个 HBox）；占位 hint 只在 empty 时存在，append 首段时已被清除，截断不会误删。
- EventList 不修改。
- 中文注释、conventional commit 格式。

并在 `append()` 方法后新增：

```java
    /** 截断保活：段数超 MAX_SEGS 时移除头部多余段（segs 与节点树同步删），并回调注入的 trim 监听。
     *  只动头部——流式段（THINK/REPLY）恒在尾部就地更新，不会被误删。 */
    private void trimHead() {
        int excess = segs.size() - MAX_SEGS;
        if (excess <= 0) return;
        double removedH = 0;
        for (int i = 0; i < excess; i++) {
            // 头部段早已布局（新段只加在尾部），layoutBounds 高度准确
            removedH += getChildren().get(i).getLayoutBounds().getHeight();
        }
        segs.subList(0, excess).clear();
        getChildren().remove(0, excess); // ObservableList.remove(from, to)：与 segs 同步删
        if (trimListener != null) trimListener.accept(removedH);
    }
```

- [ ] **Step 1: 注入 trim 监听（双 runLater 布局后补偿）**

定位 `MainWindow.java` 的 `onSessionActivated` 方法（约 210 行，`chatView.setScrollBottomRequest(() -> {...});` 之后），插入：

```java
                    // 截断保活补偿：头部段被删 → 内容变矮，vvalue（归一化）不变时视口绝对位置下移。
                    // 双 runLater 等布局跑完再读高度（layoutBounds 是布局缓存，删除后未布局仍返回旧值）；
                    // 贴底（v=1）时公式自然收敛 1.0，无需分支。
                    chatView.setTrimListener(removedH -> Platform.runLater(() -> Platform.runLater(() -> {
                        Node content = chatScroll.getContent();
                        double viewport = chatScroll.getViewportBounds().getHeight();
                        double hNow = content != null ? content.getLayoutBounds().getHeight() : 0;
                        double hOld = hNow + removedH;              // 截断前内容高度
                        double scrollableOld = hOld - viewport;     // 截断前可滚动行程
                        double scrollableNew = hNow - viewport;     // 截断后可滚动行程
                        if (scrollableOld <= 0 || scrollableNew <= 0) return;
                        double v = chatScroll.getVvalue();
                        double v2 = v * scrollableOld / scrollableNew; // 视口顶部绝对位置守恒
                        chatScroll.setVvalue(Math.max(0.0, Math.min(1.0, v2)));
                    })));
```

确认 `Node` 已 import（MainWindow 现有代码已使用 `javafx.scene.Node` 类型，无需新增 import；`Platform` 已 import）。
