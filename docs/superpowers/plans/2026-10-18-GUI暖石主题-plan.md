# GUI 暖石主题实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-10-18-GUI暖石主题设计.md` 把 minion 的 JavaFX 界面（主窗口、消息区、设置窗、全部弹窗）统一为暖石深色主题。

**Architecture:** 以 `theme.css` 为唯一样式源，按令牌表重写；Java 侧只做三件事：给节点补 styleClass、把消息段重构为「行节点 + 可选身份头」、新增 `DarkDialogs` 统一无边框弹窗。业务逻辑与流式合并保持不动。

**Tech Stack:** JDK 8、JavaFX 8（jfxrt）、Maven、JUnit 4。

## Global Constraints

- JDK 8 兼容；不新增依赖。
- 颜色全部写死十六进制 / `rgba()`；**不得使用 CSS 变量、`::before`、`transition`、`conic-gradient`**（JavaFX 8 不支持）。
- 字重只用 `normal` / `bold`。
- 所有嵌入卡片/气泡的 `MessageTextArea`，`.content` 背景必须与所在卡片底色一致（LCD 渲染规则，见 theme.css 现有注释）。
- **每个样式任务必须删除 theme.css 中旧的同名规则**：JavaFX CSS 按文件顺序后者覆盖前者，只追加不删除会导致新样式不生效。
- 消息正文保持可选择的 `TextArea`，**不得改为 TextFlow**（会丢失原生拖选/Ctrl+C）。
- 主窗口保持直角；弹窗内部圆角。
- 每个任务结束必须 `mvn -q compile` 通过；涉及 `ChatView` 的任务还要跑 `mvn -q -Dtest=ChatView*Test test`。
- commit 用中文 conventional 格式。

## 已知差异（验收时不要当 bug）

1. `TextArea` 不支持行高，正文行距比原型紧凑。
2. 事件 `EventList.Ev` 没有时间戳，AI 身份行**不显示时间、不显示模型名**（历史重放会显示错误时间，故省略）；只显示头像 + `minion`。
3. 消息正文是纯文本，原型中的代码块卡片 / 语法高亮 / diff 行着色**不实现**；工具输出整段用等宽字体 + 保留 `+/-` 前缀。
4. 主窗口直角；系统文件选择器保持原生浅色。
5. 原型侧栏底部状态行不实现。
6. 上下文环保持现有 24px 画布（不改绘制尺寸，只换颜色）。
7. 设置窗「关于」页沿用现有纵向文本布局，只统一配色；工具页每行暂不加插件图标。
8. 子代理边界不新增徽标，用 `subagent-card` 卡片 + 图标 + 文字区分。

## 文件结构

| 文件 | 职责 |
|---|---|
| `src/resource/theme/theme.css` | 全部颜色、字号、圆角、间距、状态样式（唯一视觉源） |
| `gui/TitleBar.java` | 标题栏结构（logo / 模型胶囊 / 窗口按钮） |
| `gui/MainWindow.java` | 侧栏分组头、新建按钮、页签策略、退出确认接线 |
| `gui/sidebar/SessionListView.java` | 会话行、计数属性 |
| `gui/sidebar/WorkspaceListView.java` | 工作空间行 |
| `gui/chat/ChatView.java` | 限宽、用户气泡、身份行、工具卡片、系统条 |
| `gui/chat/MessageTextArea.java` | 不改（气泡/卡片底色全部由 CSS 控制） |
| `gui/chat/CollapsibleText.java` | 不改（卡片样式类由 ChatView 从外部追加） |
| `gui/input/InputView.java` | 输入大框、chip、发送键、提示行 |
| `gui/input/ContextRing.java` | 环配色 |
| `gui/dialog/DarkDialogs.java`（新增） | 无边框弹窗封装：`create` / `decorate` |
| `gui/dialog/SettingsDialog.java` | 设置窗 5 页 |
| `gui/dialog/WorkspaceFormDialog.java`、`gui/plugin/*Dialog.java` | 表单/列表弹窗接入 `DarkDialogs` |
| `gui/dialog/ConfirmSheet.java` | 确认卡片 |
| `gui/icon/IconFactory.java` | 关键图标描边 + 加号 |

```java
static String diffStat(String diffBody) {
    if (diffBody == null || diffBody.isEmpty()) return null;
    int add = 0, del = 0;
    for (String line : diffBody.split("\n", -1)) {
        if (line.startsWith("+ ")) add++;
        else if (line.startsWith("- ")) del++;
    }
    if (add == 0 && del == 0) return null;
    return "+" + add + " \u2212" + del;
}
```

```java
/** 无边框深色弹窗：自绘标题栏（拖动 + 关闭），内容与按钮栏仍交给 DialogPane。 */
public final class DarkDialogs {

    private DarkDialogs() { }

    public static <T> Dialog<T> create(Window owner, String title, Node content, ButtonType... buttons) {
        Dialog<T> d = new Dialog<T>();
        d.initOwner(owner);
        d.initModality(Modality.APPLICATION_MODAL);
        d.getDialogPane().getButtonTypes().addAll(buttons);
        d.getDialogPane().setContent(content);
        decorate(d, title);
        return d;
    }

    public static void decorate(Dialog<?> d, String title) {
        d.initStyle(StageStyle.TRANSPARENT);
        DialogPane pane = d.getDialogPane();
        String header = pane.getHeaderText();
        pane.setHeaderText(null);
        pane.setGraphic(null);
        pane.getStyleClass().add("dark-dialog");

        Node content = pane.getContent();
        VBox body = new VBox(10);
        if (header != null && !header.trim().isEmpty()) {
            Label subtitle = new Label(header);
            subtitle.getStyleClass().add("dark-subtitle");
            body.getChildren().add(subtitle);
        }
        if (content != null) body.getChildren().add(content);

        HBox bar = titleBar(d, title);
        pane.setContent(new VBox(bar, body));

        d.setOnShown(e -> {
            Scene scene = pane.getScene();
            if (scene != null) scene.setFill(Color.TRANSPARENT);
        });
    }

    private static HBox titleBar(final Dialog<?> d, String title) {
        Label label = new Label(title);
        label.getStyleClass().add("dark-title");
        Region spacer = new Region();
        HBox.setHgrow(spacer, Priority.ALWAYS);
        Button close = new Button();
        close.setGraphic(IconFactory.close());
        IconFactory.size(close.getGraphic(), 12);
        close.getStyleClass().add("btn-close");
        close.setOnAction(e -> {
            d.setResult(null);
            d.close();
        });
        HBox bar = new HBox(10, label, spacer, close);
        bar.getStyleClass().add("dark-titlebar");
        bar.setAlignment(Pos.CENTER_LEFT);

        final double[] offset = new double[2];
        bar.setOnMousePressed(e -> {
            Window w = d.getDialogPane().getScene() == null
                    ? null : d.getDialogPane().getScene().getWindow();
            if (w == null) return;
            offset[0] = e.getScreenX() - w.getX();
            offset[1] = e.getScreenY() - w.getY();
        });
        bar.setOnMouseDragged(e -> {
            Window w = d.getDialogPane().getScene() == null
                    ? null : d.getDialogPane().getScene().getWindow();
            if (w == null) return;
            w.setX(e.getScreenX() - offset[0]);
            w.setY(e.getScreenY() - offset[1]);
        });
        return bar;
    }
}
```
