# 子代理消息配色对齐主代理 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 子代理消息（标签 + 正文）按消息类型使用与主代理完全一致的颜色，青色 `log-subagent` 仅保留在「子任务开始/完成」边界行。

**Architecture:** 零新增文件。删除 `ChatView.colorOf` 恒等映射函数，`onEventFx` 11 处调用点直传类型色类（`log-input`/`log-think`/`log-reply`/`log-tool`/`log-error`/`log-warn`/`log-sys`）；`Seg` 构造器的 `log-body-*` 派生逻辑自动跟随标签色，正文色无需单独处理；`SUB_AGENT_START`/`SUB_AGENT_DONE` 两处硬编码 `log-subagent` 不动；测试断言与 theme.css / ARCHITECTURE.md / README.md 描述同步。

**Tech Stack:** Java 8、JavaFX 8（JDK 自带 jfxrt）、Maven、JUnit 4。

**设计文档:** `docs/superpowers/specs/2026-09-18-子代理正文配色-design.md`（已获批，提交 `318950c`）

## Global Constraints

- **JDK 8 语法**（禁 `var`/`List.of`/文本块等 Java 9+ API）；注释、提交信息均中文（commit 用 conventional 格式）。
- **配色映射逐字定稿**（子代理与主代理同色）：输入 `log-input`、思考 `log-think`、回复 `log-reply`、工具调用与成功结果 `log-tool`、工具失败与错误 `log-error`、警告 `log-warn`、统计/系统 `log-sys`。
- **保留青色**：`SUB_AGENT_START`/`SUB_AGENT_DONE` 两处硬编码 `log-subagent` 不改；theme.css 的 `.log-subagent`/`.log-body-subagent` 不删除。
- **主代理零变化**：`subAgentId == 0` 的渲染结果与改动前完全一致。
- **不改**：`tagOf`、`sameStream`、`Seg` 构造器、`StreamBuffers`/`ActiveStreams`、流式/折叠/截断逻辑。
- **不做渲染层自动化测试**（配色属 JavaFX 渲染层，样式类断言需 FX 环境）：沿用现状由真机手动冒烟验证（Task 3）；`tagOf` 纯逻辑断言保留。
- 每任务结束：`mvn compile` + 相关测试全绿并提交；最后 `mvn test` 全量。
