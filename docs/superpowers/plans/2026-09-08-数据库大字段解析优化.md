> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 查询结果单元格截断透明化（标注真实长度），并新增 query `full=true` 全文模式让模型可取大字段全文。

**Architecture:** 三层递进——① MarkdownTable.cell 截断时追加 `…[完整 N 字符]`（全查询默认）；② DbExecutor.query 增 `full` 参数，全列截断线 120→20000；③ 总预算 30000 落盘兜底不变（MarkdownTable.fit 零改动）。交互闭环：概览表标注长度 → 模型发单行 SQL + `full=true` 取全文 → 超 20000 仍标注+落盘 Read。

**Tech Stack:** JDK 8、JUnit 4、Maven 单模块。

## Global Constraints

- 不改 config.properties / tools.json；不新增依赖；不新增 GUI 改动。
- SchemaGenerator 仅支持全 string 参数：full 声明为 string 类型，取值走容错解析（布尔原值/字符串大小写空白容忍）。
- 返回字符总预算 CHAR_BUDGET=30000、行数 MAX_ROWS=100、单元格默认截断 CELL_MAX=120 **均不改变**。
- 相对 spec（2026-09-08-数据库大字段解析优化-design.md）的实现简化（已获用户知悉批准路径，Task 3 回写 spec）：
  1. `render(columns, rows)` **无需**列级截断线参数——单元格值在 DbExecutor 循环内已由 `cell(v, max)` 处理完，render 只拼接；spec §4「render 透传」与 §7 测试 5 删除。
  2. full 模式截断线作用于**所有列**（内容不足截断线则原样呈现，无行为差异），不按列类型区分。

- [x] **Step 3: 实现 cell 参数化与透明标注**

将 `MarkdownTable.java` 中的 `cell(Object v)` 替换为（同一位置，替换后原方法体即委托）：

```java
/** null → 字面量 NULL；竖线转义；换行转 &lt;br&gt;；超 cellMax 截断：省略号 + 真实长度标注 */
public static String cell(Object v) { return cell(v, CELL_MAX); }

public static String cell(Object v, int cellMax) {
    if (v == null) return "NULL";
    String s = String.valueOf(v);
    int rawLen = s.length();          // 标注口径：转义（<br> 膨胀）前的真实长度
    s = s.replace("\r\n", "<br>").replace("\n", "<br>").replace("\r", "<br>");
    s = s.replace("|", "\\|");
    if (s.length() > cellMax) {
        int cut = cellMax;
        // 截断点可能切在代理对（如 emoji）中间：丢弃尾部孤立高代理（对齐 TruncatedOutput 口径）
        if (Character.isHighSurrogate(s.charAt(cut - 1))) cut--;
        s = s.substring(0, cut) + "…[完整 " + rawLen + " 字符]";
    }
    return s;
}
```

类注释与 `CELL_MAX` 行注释同步更新（说明截断会标注真实长度；`FULL_CELL_MAX` 由 DbExecutor 定义）。

/** query 的 full 参数容错解析：布尔原值 / 字符串 "true"（大小写、首尾空白容忍），缺省或畸形一律 false */
static boolean fullOf(JsonObject args) {
    if (args == null || !args.has("full")) return false;
    try {
        JsonElement e = args.get("full");
        if (e.isJsonPrimitive() && e.getAsJsonPrimitive().isBoolean()) return e.getAsBoolean();
        return Boolean.parseBoolean(e.getAsString().trim());
    } catch (RuntimeException ignored) {
        return false;
    }
}
