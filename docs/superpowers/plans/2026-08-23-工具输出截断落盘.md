# 工具输出截断落盘 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** BashTool 头尾截断（头 18k + 尾 12k）与 GrepTool 单行截断（1000 字符），两工具超限输出落盘 `<workDir>/.minion/tmp/` 供模型 Read 查看，启动时清理超 3 天旧文件。

**Architecture:** 新增 `OutputDump` 静态工具类统一落盘/尾部读取/清理逻辑；BashTool 收集阶段流式写全量落盘 + 内存保留头部，结束时按总字符决定是否保留文件并拼尾部；GrepTool 收集阶段遍历不提前终止（全量落盘）、显示层 250 条 + 30k 字符双上限、单行截断 1000 字符；Main 装配时按工作区清理。

**Tech Stack:** JDK 8、JUnit4、TemporaryFolder、Git Bash（测试执行环境，Windows）。

## Global Constraints

- 设计文档：`docs/superpowers/specs/2026-08-23-工具输出截断落盘-design.md`（已确认）
- 不超限不落盘：输出 ≤ 上限时不得产生任何临时文件，行为与现状一致
- 落盘目录：`<workDir>/.minion/tmp/`，文件名 `bash-<ts>-<seq>.log` / `grep-<ts>-<seq>.txt`
- 清理：仅删除修改时间超过 3 天（`RETENTION_MS = 3 * 24 * 3600 * 1000L`）的文件
- 返回路径：`workDir` 相对路径（如 `.minion/tmp/bash-xxx.log`），模型可直接 Read（PathsGuard 白名单内）
- 落盘失败降级：不阻断工具执行，退化为纯内存截断（无路径提示），`System.err` 记录
- JDK 8 兼容，无新依赖

```java
package com.minion.core.tools;

import java.io.File;
import java.io.IOException;
import java.io.RandomAccessFile;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.attribute.FileTime;
import java.util.concurrent.atomic.AtomicLong;

/** 工具超限输出落盘：统一落盘目录/写入/尾部读取/清理。JDK8 兼容，无新依赖。 */
public final class OutputDump {

    public static final long RETENTION_MS = 3L * 24 * 3600 * 1000;

    private static final AtomicLong SEQ = new AtomicLong();

    private OutputDump() { }

    public static Path dumpDir(Path workDir) {
        return workDir.resolve(".minion").resolve("tmp");
    }

    /** 写落盘文件 prefix-<ts>-<seq>.txt，返回路径；失败返回 null（调用方降级） */
    public static Path write(Path workDir, String prefix, String content) {
        try {
            Path dir = dumpDir(workDir);
            Files.createDirectories(dir);
            Path f = dir.resolve(prefix + "-" + System.currentTimeMillis()
                    + "-" + SEQ.incrementAndGet() + ".txt");
            Files.write(f, content.getBytes(StandardCharsets.UTF_8));
            return f;
        } catch (IOException e) {
            System.err.println("[minion] 输出落盘失败: " + e.getMessage());
            return null;
        }
    }

    /** 读文件末尾最多 maxChars 字符；UTF-8 多字节边界安全（首字符非法则丢弃）；
     *  失败返回 "" */
    public static String tail(Path file, int maxChars) {
        try {
            long len = Files.size(file);
            // 多读 3 字节容错 UTF-8 边界（单字符最多 4 字节，+4 保险）
            long start = Math.max(0, len - maxChars * 1L - 4);
            byte[] buf;
            try (RandomAccessFile raf = new RandomAccessFile(file.toFile(), "r")) {
                raf.seek(start);
                buf = new byte[(int) (len - start)];
                raf.readFully(buf);
            }
            String s = new String(buf, StandardCharsets.UTF_8);
            if (s.length() <= maxChars) return s;
            // 从尾部截到 maxChars；若首字符是不完整多字节则再丢一个字符
            String cut = s.substring(s.length() - maxChars);
            if (cut.charAt(0) == '\uFFFD' && cut.length() > 1) cut = cut.substring(1);
            return cut;
        } catch (Exception e) {
            return "";
        }
    }

    /** 删除 dumpDir 下修改时间超过 olderThanMillis 的文件；目录不存在静默返回 */
    public static void cleanup(Path workDir, long olderThanMillis) {
        try {
            Path dir = dumpDir(workDir);
            if (!Files.isDirectory(dir)) return;
            long deadline = System.currentTimeMillis() - olderThanMillis;
            Files.list(dir).forEach(p -> {
                try {
                    FileTime t = Files.getLastModifiedTime(p);
                    if (t.toMillis() < deadline) Files.deleteIfExists(p);
                } catch (IOException ignored) { }
            });
        } catch (IOException ignored) { }
    }

    /** workDir 相对路径（反斜杠转正斜杠），供返回提示与模型 Read 使用 */
    public static String workDirRelative(Path workDir, Path file) {
        return workDir.toAbsolutePath().normalize().relativize(
                file.toAbsolutePath().normalize()).toString().replace('\\', '/');
    }
}
```

注意：`tail` 中 `new String(buf, UTF_8)` 将不完整多字节解码为 U+FFFD——通过 `cut.charAt(0) == '\uFFFD'` 检查丢弃首字符。`tail_utf8Boundary` 测试的 8 字符窗口（"中文内容行\nsecond line\n" 共 19 字符，尾 8 = "d line\n" 之前是 "secon"，窗口起点在 "second" 中部）——若窗口起于多字节中间，首字符为 U+FFFD 被丢弃后以 "line\n" 结尾，断言成立。

```java
private static void appendTruncated(StringBuilder sb, String s) {
    if (sb.length() >= HEAD_MAX) return;
    int room = HEAD_MAX - sb.length();
    if (s.length() > room) {
        sb.append(s, 0, room);
    } else {
        sb.append(s);
    }
}
```

```java
/** 组装返回：未超限删落盘返回全量；超限保留落盘，返回 头 + 提示 + 尾 */
private String finishOutput(StringBuilder output, AtomicLong totalChars, Path dump) {
    if (totalChars.get() <= TOTAL_MAX) {
        if (dump != null) dump.toFile().delete();
        return output.toString();
    }
    String head = output.toString();
    String tailStr = dump == null ? "" : OutputDump.tail(dump, TAIL_MAX);
    String rel = dump == null ? "" : OutputDump.workDirRelative(workspace.workDir(), dump);
    String note = "\n... 输出已截断（共 " + totalChars.get() + " 字符，完整输出已保存到 "
            + rel + "，可用 Read 查看）...\n";
    return head + note + tailStr;
}
```

walkFileTree visitor 重写（关键：不提前终止，双计数）：

```java
Files.walkFileTree(root, new SimpleFileVisitor<Path>() {
    private final StringBuilder disp = new StringBuilder(); // 显示层
    private int dispCount = 0;   // 已入显示层条数
    private int totalCount = 0;  // 全量条数（含落盘）
    private boolean dispFull = false;

    @Override
    public FileVisitResult visitFile(Path file, BasicFileAttributes attrs) {
        Path rel = rootInWork ? workspace.cwd().relativize(file) : file;
        try {
            java.util.List<String> lines = TextFiles.readAllLines(file).lines;
            for (int i = 0; i < lines.size(); i++) {
                String line = lines.get(i);
                if (p.matcher(line).find()) {
                    totalCount++;
                    String entry = rel.toString().replace('\\', '/') + ":" + (i + 1)
                            + ": " + truncateLine(line.trim()) + "\n";
                    if (dumpWriter != null) {
                        try { dumpWriter.write(entry); } catch (IOException ignored) { }
                    }
                    if (!dispFull) {
                        disp.append(entry);
                        dispCount++;
                        if (dispCount >= max || disp.length() >= DISPLAY_CHARS) {
                            dispFull = true; // 显示层满了，继续遍历但不再 append
                        }
                    }
                }
```
