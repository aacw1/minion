# 压缩中防重复点击 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 环形进度圈在压缩进行中（自动/手动）不可点击，Tooltip 文案显示"正在压缩中"。

**Architecture:** 复用既有 `compressing` 状态（自动/手动压缩路径均已推送 `onCompressingChanged`）：ContextRing 点击判定与 Tooltip 文案纳入该状态；InputView 在提交压缩任务后立即置位，消除状态推送前的窗口期。全部改动在 UI 层。

**Tech Stack:** JDK 8、JavaFX 8、JUnit 4、Maven。

## Global Constraints

- JDK 8 兼容；构建/测试命令固定为 `JAVA_HOME="D:\javame\jdk1.8" mvn test`
- 不修改 core 层 `compactNow`（不加核心层重入保护，spec 已确认）

- [ ] **Step 3: 实现 ContextRing 三处改动**

`compressable` 静态方法（原两参 → 三参）：

```java
/** 可点击压缩判定：非压缩中、非运行中且占比 > 30%（严格超过；静态可单测） */
static boolean compressable(boolean compressing, boolean running, double pct) {
    return !compressing && !running && pct > COMPRESS_HINT_PCT;
}
```

`setOnMouseClicked` 回调（压缩中不可点）：

```java
setOnMouseClicked(e -> {
    if (compressable(compressing, running, pct()) && onCompress != null) onCompress.run();
});
```

`refreshTooltip` 文案优先级：`compressing`（"正在压缩中"）> `running`（"运行中不可压缩"）> 超 30%（"点击立即压缩"）> 空；可见性 `over || compressing`（手动 /compact 可能在 ≤30% 时触发，压缩中必须显示文案）：

```java
private void refreshTooltip() {
    infoLine.setText(formatInfo(used, max, threshold));
    boolean over = pct() > COMPRESS_HINT_PCT;
    if (compressing) {
        hintLine.setText("正在压缩中");
    } else {
        hintLine.setText(over ? (running ? "运行中不可压缩" : "点击立即压缩") : "");
    }
    hintLine.setVisible(over || compressing);
    hintLine.setManaged(over || compressing);
}
```

将 `InputView.java` 的 `setOnCompress` 回调改为：

```java
contextRing.setOnCompress(new Runnable() {
    @Override public void run() {
        SessionHandle h = current;
        if (h == null || h.running) return;
        contextRing.setCompressing(true); // 提交后立即防重；onCompressingChanged(false) 自然恢复
        h.pool.execute(new Runnable() {
            @Override public void run() { h.loop.compactNow(); }
        });
    }
});
```
