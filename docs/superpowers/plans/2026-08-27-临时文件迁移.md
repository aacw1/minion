# 临时文件迁移到 .session/tmp/<会话id>/ 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 工具超限落盘与模型自建临时文件从工作空间迁到 jar 运行目录的 `.session/tmp/<会话id>/`，删除会话时一并清理，提示词同步引导。

**Architecture:** OutputDump API 从"基于 workDir"改为"基于会话临时目录"；`SessionManager.newRegistry` 每会话注入 tmpDir（`jarDir/.session/tmp/<sessionId>`）；PathsGuard 增加 tmpDir 白名单使模型 Read/Write 免确认；deleteSession/deleteWorkspace 递归清理；SystemPromptBuilder 注入临时目录与 Git Bash 规则说明。

**Tech Stack:** JDK 8、Maven（junit4、mockwebserver）、Gson、flexmark。

## Global Constraints

- JDK 8 兼容：不用 `var`、`List.of`、`Files.walk` 需 try-with-resources 关流；lambda/方法引用可用（JDK8 支持）。
- 构建命令：`JAVA_HOME="D:\javame\jdk1.8" mvn test -Dtest=<测试类>`（单测）或 `JAVA_HOME="D:\javame\jdk1.8" mvn test`（全量）。
- 文档、注释、commit 均用中文；commit 用 conventional 格式，结尾加 `Co-Authored-By: Claude <noreply@anthropic.com>`。
- 会话临时目录结构：`<jarDir>/.session/tmp/<sessionId>/`；会话 id 为 `yyyyMMdd-HHmmss-SSS-NNNN`（无非法字符）。
- 兼容原则：所有工具/构造器保留旧签名（委托新签名，tmpDir=null），已存在的测试不因签名变化而编译失败；仅行为断言按新目录更新。
- Bash 执行用 pid 探针/命令脚本（系统临时目录）**不迁移**。

改写 `src/main/java/com/minion/core/tools/OutputDump.java`（保留 `RETENTION_MS`、`SEQ`、`tail` 不动）：

```java
    /** 写落盘文件 prefix-<ts>-<seq>.txt 到会话临时目录；tmpDir 为 null 或失败返回 null（调用方降级） */
    public static Path write(Path tmpDir, String prefix, String content) {
        if (tmpDir == null) return null;
        try {
            Files.createDirectories(tmpDir);
            Path f = tmpDir.resolve(prefix + "-" + System.currentTimeMillis()
                    + "-" + SEQ.incrementAndGet() + ".txt");
            Files.write(f, content.getBytes(StandardCharsets.UTF_8));
            return f;
        } catch (IOException e) {
            System.err.println("[minion] 输出落盘失败: " + e.getMessage());
            return null;
        }
    }
```

`dumpDir(Path workDir)` 与 `workDirRelative(Path workDir, Path file)` 整体删除。`cleanup` 改写为扫所有会话子目录：

```java
    /** 删除 tmpRoot（jarDir/.session/tmp）下所有会话子目录中修改时间超过 olderThanMillis 的文件；
     *  子目录本身保留（会话未删除时旧文件允许保留供回溯）。目录不存在静默返回 */
    public static void cleanup(Path tmpRoot, long olderThanMillis) {
        try {
            if (!Files.isDirectory(tmpRoot)) return;
            long deadline = System.currentTimeMillis() - olderThanMillis;
            try (Stream<Path> dirs = Files.list(tmpRoot)) {
                dirs.filter(Files::isDirectory).forEach(d -> {
                    try (Stream<Path> stream = Files.list(d)) { // 流须关闭，否则 Windows 目录句柄泄漏
                        stream.forEach(p -> {
                            try {
                                FileTime t = Files.getLastModifiedTime(p);
                                if (t.toMillis() < deadline) Files.deleteIfExists(p);
                            } catch (IOException ignored) { }
                        });
                    } catch (IOException ignored) { }
                });
            }
        } catch (IOException ignored) { }
    }
```

    /** 递归删除目录（文件占用失败静默跳过；JDK8 Files.walk 需 try-with-resources 关流） */
    private void deleteRecursively(Path dir) {
        if (!Files.isDirectory(dir)) return;
        try (Stream<Path> s = Files.walk(dir)) {
            s.sorted(Comparator.reverseOrder()).forEach(p -> {
                try { Files.deleteIfExists(p); } catch (IOException ignored) { }
            });
        } catch (IOException ignored) { }
    }
