# 运行状态指示器弹窗遮挡补充 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 工具提问弹窗（ConfirmSheet）显示期间隐藏运行状态指示器；修复窗口化时指示器遮挡正文最后一行的问题。

**Architecture:** RunningIndicator 增加可见性自洽（visibleProperty 监听停/启动动画）与 suspend()/resume() 挂起恢复；ConfirmSheet 增加静态可见性回调；MainWindow 注册联动；ChatView 底部 padding 12→40px 为指示器让位。

**Tech Stack:** Java 8 / JavaFX 8（Timeline 动画、visibleProperty 监听、Consumer 回调）

## Global Constraints

- JDK 8 / JavaFX 8 兼容（不可用 JavaFX 12+ API，如 StackPane.setFillWidth）
- 动画停止须防引用泄漏（StatusDot 规约：隐藏前必须停全部 Timeline 并置空引用）
- 跨线程回调一律 Platform.runLater 包装（ConfirmSheet 回调本身在 FX 线程，包装为防御性一致）
- 压缩状态事件 try/finally 成对（本次不涉及，不得破坏）
- gui 测试只测纯静态逻辑（本次无新增自动化测试）
- 中文注释 + conventional commit 格式
- 完成前自查：mvn compile + 全量测试（587 用例）通过

### Task 1: RunningIndicator 可见性自洽 + suspend/resume

**Files:**
- Modify: `src/main/java/com/minion/gui/RunningIndicator.java`

**Interfaces:**
- Consumes: 无（现有类，构造器/字段/方法均已知）
- Produces: `void suspend()`、`void resume()`（供 Task 3 MainWindow 调用）；visibleProperty 监听行为

- [ ] **Step 1: 构造器注册 visibleProperty 监听**

在 `RunningIndicator()` 中 `setVisible(false)` 之后追加：

```java
// 可见性自洽：手动隐藏（弹窗遮挡等）时停动画防泄漏；恢复可见且运行中时重启动画
visibleProperty().addListener((obs, ov, nv) -> {
    if (!nv) {
        stopAnimations();
    } else if (running) {
        text.setText(displayText(compressing, pickText(rnd)));
        startAnimations();
    }
});
```

- [ ] **Step 2: setRunning(true) 改为经 setVisible 收敛动画启动**

将 `setRunning` 中 true 分支改为只设状态并委托可见性监听：

```java
        this.running = running;
        if (!running) {
            compressing = false;
            stopAnimations();
            setVisible(false);
            return;
        }
        setVisible(true); // 动画启动收敛到 visibleProperty 监听（见构造器）
```

删除原 true 分支的 `text.setText(...)` 与 `startAnimations()` 两行（监听中已有）。

- [ ] **Step 3: 新增 suspend()/resume()**

在 `setCompressing` 方法后新增：

```java
    /** 弹窗遮挡期间挂起：仅隐藏（visible 监听自动停动画），保留 running/compressing 状态 */
    public void suspend() {
        setVisible(false);
    }

    /** 弹窗关闭后恢复：会话仍运行则重新显示（visible 监听重启动画）；否则保持隐藏（防弹窗期间会话已结束） */
    public void resume() {
        setVisible(running);
    }
```

### Task 2: ConfirmSheet 可见性回调

**Files:**
- Modify: `src/main/java/com/minion/gui/dialog/ConfirmSheet.java`

**Interfaces:**
- Consumes: 无（静态类现有 setHost 模式）
- Produces: `static void setVisibilityListener(Consumer<Boolean>)`（供 Task 3 注册；true=弹窗显示，false=弹窗完全关闭）

- [ ] **Step 1: 新增静态字段与注册方法**

在 `setHost` 后新增：

```java
    private static Consumer<Boolean> visibilityListener;

    /** 注册弹窗可见性回调：true=显示，false=完全关闭（淡出完成）；MainWindow 用于挂起/恢复运行状态指示器 */
    public static void setVisibilityListener(Consumer<Boolean> listener) { visibilityListener = listener; }
```

需在类顶部字段区加 `private static Consumer<Boolean> visibilityListener;`（字段声明与 setter 相邻放置），并确保 `import java.util.function.Consumer;` 已存在（文件已导入，见 ConfirmSheet.java 头部）。

- [ ] **Step 2: display() 回调 true**

`display` 方法中 `showing = true;` 之后追加：

```java
        if (visibilityListener != null) visibilityListener.accept(true);
```

- [ ] **Step 3: finish() 淡出完成后回调 false**

`finish` 的 `out.setOnFinished` handle 中 `showing = false;` 之后追加：

```java
                if (visibilityListener != null) visibilityListener.accept(false);
```

（`pending.poll()` 出队下一个 display 前先回调 false，再于 display 中回调 true，顺序天然正确）
