# 会话视图缓存增量重放 — 实施计划

日期：2026-08-16
来源：[设计文档](../specs/2026-08-16-会话视图缓存增量重放-design.md)

## 步骤

1. **EventList.rebind(Listener, int)**：锁内原子「快照 [from, size) + 注册直通」，add 同锁互斥无竞态
2. **ChatView**：`bind(active)` 增量重放（`replayed` 游标，直通渲染完成才推进）；`clear()` 重置游标；`rememberVvalue/savedVvalue` 滚动位置保存
3. **MainWindow**：`viewCache`（id → ChatView）+ onSessionActivated 缓存分支（切走记滚动位置、命中复用恢复）；删除会话两处、切工作空间清缓存；`clearChatPane` 不毁视图内容（setContent 占位）
4. **EventListTest**：rebind 快照/直通/二次不重复/越界 clamp 四用例
5. **验证**：mvn test 全过；BenchSwitch 回归（热切换 110~726ms → 25~259ms，队列即时排空）
